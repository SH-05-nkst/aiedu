MENACE シミュレータ

マッチ箱とビーズで学ぶ○×ゲームのAI(Michie, 1961)をブラウザで再現します。MENACEが先手(×)、あなたが後手(○)です。

対戦

「新しいゲーム」を押してください。

最後に使った箱

空きマスの数字が、その手のビーズの数です。

ランダムな相手と、たくさん対戦させる

対戦数 0 / MENACEの勝ち 0 / 引き分け 0 / 負け 0 / 使われた箱 0

グラフは20回ごとの割合です(青:勝ち、灰:引き分け、赤:負け)。

ルール:箱ごとに、手の種類のビーズが入っています(最初の手は4個ずつ、3手目は3個、5手目は2個、7手目は1個)。MENACEは、いまの盤面の箱からビーズを1個引き、その手を打ちます。
終わったあと、使ったビーズに勝ち:+3個、引き分け:+1個、負け:−1個を行います。ビーズが全部なくなった箱では「投了」(負け)とし、箱を最初の状態にもどします。
回転・裏返しで同じ形になる盤面は、1つの箱にまとめています。
