ヘキサポーン シミュレータ

3×3マスで、ポーンを3つずつ動かすゲームです。Gardner(1962)のマッチ箱の機械を再現します。あなたが白(先手)、機械が黒(後手)です。

対戦

「新しいゲーム」を押してください。

最後に使った箱

矢印が箱の中のビーズ(手)、数字がビーズの数です。

相手と、たくさん対戦させる

対戦数 0 / 機械の勝ち 0 / 機械の負け 0 / 使われた箱 0 / ビーズがなくなった箱 0

グラフは20回ごとの割合です(青:機械の勝ち、赤:機械の負け)。

ゲームのルール:ポーンは前に1マス進めます(前のマスが空のときだけ)。ななめ前に相手のポーンがいるときは、取ることができます。次のどれかで勝ちです。①相手側の端の列まで進む ②相手のポーンをすべて取る ③相手が動かせなくなる。
機械のしくみ:盤面ごとに箱があり、動かせる手の数だけビーズが1個ずつ入っています。機械は箱からビーズを1個引き、その手を打ちます。負けたときは、最後に打った手のビーズを1個取り除きます(勝ったときは何もしません)。箱のビーズがすべてなくなったら「投了」して負けとし、その1つ前の手のビーズを取り除きます。左右を裏返すと同じ形になる盤面は、1つの箱にまとめています。
見どころ:このゲームは、後手(黒)が正しく打てば必ず勝てます。対戦をくり返すと、負けにつながる手のビーズがなくなり、機械はだんだん負けなくなります。「ビーズがなくなった箱」は、どの手を打っても負ける局面を、機械が見つけた印です。
